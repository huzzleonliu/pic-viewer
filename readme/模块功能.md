# 模块功能

按界面模块说明「能做什么」和关键限制。部署参数见 [部署](部署.md)，内部数据流见 [流程结构](流程结构.md)。

## 顶栏

- 显示托管根的真实路径（`get_root_info`）。
- 当前模式文案：`图片` 或 `文本`。
- **图片模式开关**：缩略图、标记、筛选、导出、简单调整。
- **文本模式开关**：简单调整、界面设置（字体大小、浅色、行号）。
- **文件管理器**：关掉后左侧栏隐藏，右侧预览仍可用。

默认：缩略图、简单调整、文件管理器开；标记 / 筛选 / 导出关。

底栏：状态句 + 当前相对路径 + 勾选数量。

## 文件管理器

两行工具：「当前项」针对树里高亮的一项；「已选」针对勾选集合。剪贴板提示显示复制或剪切内容。

### 当前项

| 按钮 | 行为 |
| --- | --- |
| 新建目录 | 在当前目录（选中目录，或文件的父目录）弹出对话框 |
| 新建文件 | 默认名 `新建文件.txt`，创建空文件并选中（按文本打开） |
| 复制路径 | 复制相对 `PIC_ROOT` 的路径，便于填导出目录 |
| 复制 / 剪切 | 不能对根目录操作 |
| 粘贴 | 贴到当前目录；剪切跨设备失败时会先拷再删源 |
| 重命名 / 删除 | 根目录不可；删除有确认框 |
| 刷新 | 重拉已展开目录，**不清空勾选**，展开状态保留 |

### 已选

| 按钮 | 行为 |
| --- | --- |
| 全选 | 列出**当前目录**（以正在看的图的父目录为准）下全部非根项并勾上 |
| 全不选 | 清空勾选 |
| 复制 / 剪切 / 粘贴 / 删除 | 针对勾选集合 |
| 刷新 | 清空勾选后重拉列表 |

树最左一列是勾选框（含目录）。根 `/` 不可勾。剪切中的项有「剪起」样式。双击目录或点箭头展开；展开集合保存在内存里，刷新不收起。

粘贴进子目录后该目录保持展开。重名时服务端 `unique_dest` 生成 `name (1).ext`。

点文件名以 `.` 开头的条目不会出现在列表中。

## 图片预览（简单调整）

- 缩放、旋转（↺ ↻）、重置、保存旋转到文件。
- 上一张 / 下一张；预览区左右约 10% 点击同样切图。
- 滚轮缩放；拖拽平移。
- **原图**：勾选走 `/media` 原文件；不勾选走 imgproxy 预览。切换图片时勾选保持。
- **包括子目录**：胶片条和元数据索引递归当前目录。列表上限约 10000 张，超出截断并提示。
- 右下角「选择」勾选当前预览图。

主图加载失败显示「无法加载图片」。未选图时显示空状态说明。

浏览器原生不一定能显示 HEIC；应用侧可能把它嗅探为图片，预览仍可能失败。PSD 不按图片嗅探。

## 胶片条（缩略图）

- 仅图片模式且「缩略图」打开时显示。
- 每页 100 张；不足一页不显示翻页芯片。
- 芯片两行：上一页 / 下一页，以及 `当前页/总页`（如 `2/9`）。
- 滚轮在胶片条上转为横向滚动。
- 缩略图懒加载。点缩略图打开该图；右下角小勾选同步到已选列表。
- 筛选生效时只显示命中路径；切图仍按过滤后的完整序列，并自动翻页。

## 标记栏

- 1–5 星，再点同一颗星清除。写入 EXIF Rating（及百分数标签）。
- tag 文本框，逗号分隔；输入 400 ms 防抖写入，Enter 立即写。
- **批量标记**：把当前星标写入所有勾选图片，并把当前 tag 追加到各文件（已有的不重复）。失败项弹列表，可复制文件名。

无勾选图片时批量按钮禁用。

## 筛选栏

打开后对当前胶片目录建元数据索引（与「包括子目录」一致）。未就绪时按钮提示 `读取元数据 done/total`。

| 条件 | 说明 |
| --- | --- |
| 星标 | 不限 / `<` `<=` `=` `>=` `>` + 0–5 |
| tag | 全等 / 包含 / 不包含 |
| 补集 | 对上述结果取反 |

「确认」把命中路径写入 `filter_paths`，胶片条只显示这些图。「重置」清条件并取消过滤。索引在进程内存，重启丢失（EXIF 仍在文件里）。

## 导出栏

针对**已勾选的图片**（忽略勾选的目录 / 文本）。

| 项 | 选项 |
| --- | --- |
| 导出到 | 下载到本机；当前目录；特定目录（相对托管根，如 `export/out`） |
| 格式 | JPEG、PNG、WebP、GIF、BMP、TIFF、原图 |

多张「下载到本机」打成 zip。写回目录时若成功会刷新文件树。部分失败弹出失败列表。

## 文本编辑器

当选中项为文本时占据右侧（图片预览隐藏但仍挂在 DOM 里）。

- 加载失败或非文本会提示，不可保存。
- 未保存修改可重置。
- 界面设置：字号 12–28、浅色背景、行号。
- 读文件 >2 MB 或写内容 >8 MB 被拒绝。
- 空文件（新建）头字节视为文本，可编辑。

## 对话框

- 删除确认：单文件显示名，多项显示数量。
- 重命名 / 新建目录 / 新建文件：名称不能为空、不能为 `.` `..`、不能含路径分隔符或控制字符。
- 失败列表：导出或批量标记的错误，可复制文件名列表。

## 格式与识别（和界面相关）

扩展名快路径（不全依赖扩展名）：常见位图为图片；`mp4`/`webm` 等为视频；`txt`/`md`/`json` 等为文本。`svg` 无扩展名快路径，靠文件头当文本（XML）。

文件头还能识别 PNG/JPEG/GIF/WebP/BMP/TIFF/ICO、HEIC/AVIF（作 Image）、MP4 等（Video）、ZIP/PDF（Other）。列表分类用「扩展名优先，否则嗅探」。
